# Modem Işıkları Kırmızı Ritüeli

Bu depo bir şaka değildir. Bu depo bir şakadır. İkisi aynı anda geçerlidir, tıpkı modemin hem internet verdiğini hem vermediğini iddia etmesi gibi.

## Resmi görev

Evde bütün ışıklar kırmızı yandığında vatandaş iki şey yapar: fişi çeker ve birine bakar. Bu daire, o bakışın süresini, fişin havada kalma saniyesini ve küfürün yasal muhatabını hesaplar.

Karar bağlayıcıdır. Operatör bunu bilmez. Modem de bilmez. Siz bilirsiniz, sonra yine fişi çekersiniz.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. İnternet de yoktur, zaten onun için buradayız.

```bash
python3 modem_ritueli.py
python3 modem_ritueli.py --kirmizi 4 --kopuk 18 --kisi 3 --saat 23
```

## Bilimsel yöntem

1. Kırmızı ışık sayılır. Mavi yanıyorsa ritüel ertelenir, çay içilir.
2. Kopukluk dakikası 12'yi geçtiyse bekleme süresine umutsuzluk eklenir.
3. Saat 02:00 ile 05:00 arasındaysa komşu da uyandırılabilir. Bu maddenin hukukî dayanağı yoktur. Duygusal dayanağı vardır.
4. Evde tek kişiyseniz küfür modeme gider. Kalabalıksanız kibarca herkese gider, sonra yine modeme gider.
